# Sistema Gestor de Ventas e Inventario Express

## Descripción

Este proyecto es un sistema básico de ventas e inventario desarrollado en C# con .NET 8.

El programa permite registrar productos, consultar el inventario, realizar ventas y consultar un reporte de caja y estadísticas de las ventas realizadas durante la ejecución.

## Funcionalidades

* Registrar nuevos productos.
* Validar el nombre, precio y stock.
* Evitar productos repetidos.
* Consultar el inventario completo.
* Mostrar alertas cuando un producto tiene bajo stock.
* Registrar ventas.
* Aplicar un descuento del 10% a clientes frecuentes.
* Calcular IVA del 19%.
* Actualizar el stock después de cada venta.
* Mostrar un ticket de venta.
* Consultar estadísticas de caja.
* Mostrar el producto con mayor cantidad de unidades vendidas.

## Tecnologías utilizadas

* C#
* .NET 8
* Listas `List<T>`
* Métodos estáticos
* `if / else`
* `switch`
* Ciclos `for`, `while` y `do-while`
* `TryParse`
* Manejo de validaciones

## Cómo ejecutar el proyecto

1. Clonar el repositorio:

```bash
git clone URL_DEL_REPOSITORIO
```

2. Entrar a la carpeta del proyecto:

```bash
cd NOMBRE_DEL_PROYECTO
```

3. Ejecutar el programa:

```bash
dotnet run
```

4. Para comprobar que el proyecto compila correctamente:

```bash
dotnet build
```
